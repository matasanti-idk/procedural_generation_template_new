# Contributing to the Procedural Generation Template



If you use this template and find bugs, poorly written code, or security issues, please feel free to contribute or suggest improvements!
This is a small, focused project, and we want to keep things simple and easy for everyone. Whether you are fixing a typo, solving a bug, or adding a new feature, your help is highly appreciated.

---

##  How Can I Contribute?

### 1. Reporting Bugs & Suggesting Features
* Check the **Issues** tab first to see if it has already been reported.
* If not, open a new Issue and describe the problem or your idea clearly.

### 2. Contributing Code Changes
We love community improvements! To submit code:
1. **Fork** the repository and create your branch from `main`.
2. Keep your changes **small and focused**—ideally one specific fix or feature per pull request (PR).
3. If you introduce new logic or fix a bug, please include a quick explanation of how you tested your changes in the PR description.
4. Open a **Pull Request** against our `main` branch.

---

## Code Style & Guidelines

* **Keep it Clean:** Write readable code and add comments for complex or non-obvious logic.
* **No Massive Overhauls:** Please avoid breaking changes or massive architectural rewrites without discussing them in an Issue first. 
* **Be Respectful:** Treat everyone in this community with kindness and respect.

---

## Need Help?

If you have questions about the code, templates, or logic, feel free to open an Issue with the label `question`, and we will get back to you as soon as possible!
